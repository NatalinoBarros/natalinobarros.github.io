# Portfólio — Natalino

Portfólio pessoal em HTML/CSS/JavaScript, preparado para publicação como site profissional e uso no LinkedIn.

## Estrutura

- `index.html`
- `styles.css`
- `script.js`

## Antes de publicar

Abra `script.js` e altere:

```js
const PROFILE = {
  linkedin: "https://www.linkedin.com/in/SEU-USUARIO",
  github: "https://github.com/SEU-USUARIO",
  email: "mailto:SEU-EMAIL"
};
```

## Publicação rápida

### GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os três arquivos.
3. Vá em `Settings > Pages`.
4. Em `Build and deployment`, selecione `Deploy from a branch`.
5. Escolha `main` e `/root`.
6. O GitHub gerará uma URL pública.

### Vercel

Você também pode importar o repositório diretamente no Vercel e publicar sem configuração adicional.

## Segurança / exposição
